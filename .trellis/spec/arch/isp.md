# isp

业务逻辑:
- 运营商表每 10 分钟刷新, 内容不变不重建; 加载失败 60 秒内不重试, 期间旧表继续服务.
- 表行格式 "<运营商> <CIDR>", 总量不超过 4MiB; 运营商名白名单校验, 保留名 national 禁用, 非法行静默跳过; china-operator-ip 类分运营商文件的公开列表经任何合并输出该行格式的端点即可直接消费.
- v4 与 v6 独立查找结构; 同地址命中多网段取最长前缀 (嵌套取最精确).
- 识别永不阻塞查询: 未配置, 未命中, 加载失败均回落 (由调用方走全国层).

对外接口:

```go
func ScopeOf(ctx context.Context, clientIP string, cfg *config.Config) (scope string, ok bool)
func Reset()
```

数据所有权: v4/v6 排序区间表与父指针; 上次加载时刻.

扩展规则:
- 表格式解析集中一处; 新校验规则追加在解析内.
- 保留名校验不可移除 (与全国池 scope 冲突).
- 查找结构可换 (区间表换前缀树), 对外语义不变.

事件目录: 无.
