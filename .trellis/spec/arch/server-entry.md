# 服务端入口

业务逻辑:
- 读配置, 构建 httpapi 并运行; 阻塞等待 SIGTERM/SIGINT.
- 收到信号: 停止接收新请求 → 快照落盘 (配置了 CACHE_PERSIST_PATH 时: 缓存快照 + pool/h3/ech 三份探针态, 后者路径由缓存路径所在目录派生) → 退出.
- 启动时先回读快照再监听, 探针态无需等下一次上报; 快照缺失或损坏不阻塞启动.
- 后台刷新任务 (cfrange 每日, hubfeed, 缓存定时快照) 由本入口统一 ctx 调度; isp 表为查询驱动的惰性刷新 (住 isp 模块), 入口不调度.

对外接口: 命令行 `cfdoh`, 无子命令; 环境变量与配置文件驱动.

数据所有权: — .

扩展规则:
- 入口保持薄壳, 不承载业务逻辑.
- 退出次序 (停收 → 快照 → 退) 不可调换.

事件目录: 无 (listening 由 httpapi 发射).
